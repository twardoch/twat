**Natural-Language Formal Specification of the Midjourney Prompting Syntax**

Midjourney is an AI-powered image generation tool that creates images based on user-provided prompts. A prompt in Midjourney consists of descriptive text, optional image URLs, and parameters that modify how the image is generated. The syntax allows users to control various aspects of the image, such as composition, style, and content. Below is a formal specification of the Midjourney prompting syntax in natural language.

--------------------------------------------------------------------------------

# **Basic Structure of a Prompt**

A Midjourney prompt generally follows this structure:

```
/imagine prompt: [Image URLs] [Text Description] [Parameters]
```

* **Image URLs (Optional):** Direct links to images that influence the style, content, or composition of the generated image.
* **Text Description:** A natural language description of the desired image.
* **Parameters (Optional):** Options that adjust how the image is generated, such as aspect ratio, styling, and other settings.

--------------------------------------------------------------------------------

# **Detailed Specification**

## **1\. Image Prompts**

* **Syntax:** Place one or more image URLs at the beginning of the prompt.



```
[Image_URL1] [Image_URL2] ... [Text Description] [Parameters]
```

* **Requirements:**

+ The image URL must be a direct link ending with `.png`,  `.jpg`,  `.jpeg`,  `.gif`, or `.webp`.
+ Multiple image URLs can be included, separated by spaces.

* **Usage:** Using images as prompts influences the style, composition, and colors of the generated image.
* **Example:**



```
https://example.com/image1.jpg https://example.com/image2.png A serene landscape with mountains
```

## **2\. Text Description**

* **Syntax:** A natural language phrase or sentence describing the desired image.
* **Guidelines:**

+ Be specific and concise.
+ Focus on what you want to include rather than what to exclude.
+ Use descriptive language to convey the subject, style, mood, and other important attributes.

* **Components to Consider:**

+ **Subject:** Person, animal, object, scene, etc.
+ **Medium:** Photo, painting, illustration, sculpture, etc.
+ **Style:** Realistic, abstract, cartoonish, etc.
+ **Lighting:** Soft, dramatic, neon, natural, etc.
+ **Color Scheme:** Vibrant, monochromatic, pastel, etc.
+ **Mood:** Cheerful, somber, mysterious, etc.
+ **Composition:** Close-up, wide shot, portrait, landscape orientation, etc.

* **Example:**



```
A watercolor painting of a golden retriever puppy playing in a field of flowers
```

## **3\. Parameters**

Parameters are options added at the end of the prompt to adjust how the image is generated. Each parameter starts with two hyphens `--` followed by the parameter name and its value.

* **Syntax:**



```
--parameter_name value
```

* **Placement:** Place parameters after the text description, separated by spaces.

Below are the available parameters and their specifications:

### **3.1\. Aspect Ratio ( `--aspect` or `--ar` )**

* **Purpose:** Changes the width-to-height ratio of the generated image.
* **Syntax:**



```
--ar <width>:<height>
```

* **Default:** `--ar 1:1` (square image)
* **Examples:**

+ `--ar 16:9` for widescreen images.
+ `--ar 9:16` for portrait-oriented images.

* **Notes:**

+ Use whole numbers for width and height.
+ The aspect ratio affects the image composition.

### **3.2\. Chaos ( `--chaos` or `--c` )**

* **Purpose:** Influences the variation and randomness of the generated images.
* **Syntax:**



```
--chaos <value>
```

* **Value Range:** `0` to `100`
* **Default:** `--chaos 0`
* **Description:**

+ Higher values result in more diverse and unexpected images.
+ Lower values produce more consistent and predictable images.

* **Example:**



```
--chaos 50
```

### **3.3\. Tile ( `--tile` )**

* **Purpose:** Generates images that can be used as repeating tiles for seamless patterns.
* **Syntax:**



```
--tile
```

* **Usage:** Add `--tile` to create images suitable for patterns on fabrics, wallpapers, textures, etc.
* **Example:**



```
--tile
```

### **3.4\. No Parameter ( `--no` )**

* **Purpose:** Excludes specified elements from the generated image.
* **Syntax:**



```
--no <element1>, <element2>, ...
```

* **Description:** Lists items to be omitted from the image.
* **Example:**



```
--no fruit, insects, cars
```

### **3.5\. Repeat ( `--repeat` or `--r` )**

* **Purpose:** Runs the prompt multiple times.
* **Syntax:**



```
--repeat <number>
```

* **Value Limits:**

+ **Basic Subscribers:** `2` to `4`
+ **Standard Subscribers:** `2` to `10`
+ **Pro and Mega Subscribers:** `2` to `40`

* **Usage:** Generates multiple images from the same prompt efficiently.
* **Example:**



```
--repeat 5
```

### **3.6\. Stylize ( `--stylize` or `--s` )**

* **Purpose:** Controls how strongly artistic styles are applied to the image.
* **Syntax:**



```
--stylize <value>
```

* **Value Range:** `0` to `1000`
* **Default:** `--stylize 100`
* **Description:**

+ Lower values make the image more closely adhere to the prompt.
+ Higher values apply more artistic style and creativity.

* **Example:**



```
--stylize 250
```

### **3.7\. Weird ( `--weird` or `--w` )**

* **Purpose:** Introduces unconventional and unexpected elements into the image.
* **Syntax:**



```
--weird <value>
```

* **Value Range:** `0` to `3000`

* **Default:** `--weird 0`

* **Description:** Higher values result in weirder images.
* **Example:**



```
--weird 500
```

* **Note:** This is an experimental feature, and results may vary.

### **3.8\. Style ( `--style` )**

* **Purpose:** Adjusts the aesthetic style of the image.
* **Syntax:**



```
--style <style_name>
```

* **Available Styles:**

+ `raw`: Reduces default stylization for more control.

* **Usage:** Use `--style raw` for less automatic beautification.
* **Example:**



```
--style raw
```

### **3.9\. Seed ( `--seed` )**

* **Purpose:** Sets the random seed for image generation to reproduce or approximate specific results.
* **Syntax:**



```
--seed <number>
```

* **Value Range:** `0` to `4294967295` (whole numbers)
* **Description:** Using the same seed with the same prompt produces similar images.
* **Example:**



```
--seed 123456
```

### **3.10\. Image Weight ( `--iw` )**

* **Purpose:** Adjusts the influence of image prompts relative to text prompts.
* **Syntax:**



```
--iw <value>
```

* **Default:** `--iw 1`

* **Value Range:** Model-dependent (e.g., `0` to `3` for Version 6)
* **Description:** Higher values give more weight to the images.
* **Example:**



```
--iw 1.5
```

### **3.11\. Version ( `--v` )**

* **Purpose:** Specifies the Midjourney model version to use.
* **Syntax:**



```
--v <version_number>
```

* **Available Versions:** `4` , `5` , `5.1` , `5.2` , `6` , etc.
* **Example:**



```
--v 5.1
```

### **3.12\. Niji Model ( `--niji` )**

* **Purpose:** Uses the Niji model version, optimized for anime and illustrative styles.
* **Syntax:**



```
--niji
```

* **Example:**



```
--niji
```

### **3.13\. Multi-Prompts**

* **Purpose:** Blends multiple concepts by separating them with double colons `::` .
* **Syntax:**



```
[Concept1] :: [Concept2] :: [Concept3] ...
```

* **Weights (Optional):**

+ Assign weights to each concept to influence their importance.
+ Syntax:


```
[Concept1] :: <weight1> [Concept2] :: <weight2> ...
```

+ Weights are normalized internally.

* **Example:**



```
sky ::3 mountains ::1
```

+ The sky will have three times more influence than the mountains.

### **3.14\. Permutation Prompts**

* **Purpose:** Quickly generates multiple variations of a prompt using lists of options.
* **Syntax:**



```
[Text before] {option1, option2, option3} [Text after]
```

* **Nested Options (Optional):** Use nested curly braces for more complex combinations.
* **Example:**



```
A {red, blue, green} balloon flying over a {city, forest, ocean}
```

* **Result:** Generates prompts for every combination of colors and locations.

# **Usage Guidelines**
* **Combining Parameters:** Multiple parameters can be used together by adding them at the end of the prompt, each preceded by `--`.



```
--parameter1 value1 --parameter2 value2
```

* **Order of Elements:** Image URLs first (if any), followed by the text description, then parameters.
* **Prompt Length and Clarity:**

+ Be as specific as necessary to convey your idea.
+ Avoid long lists of instructions; focus on key descriptive elements.
+ Use precise language and specific terms to achieve better results.

* **Plurality and Numbers:**

+ Use specific numbers or collective nouns for clarity.
+ Example: Use "three cats" instead of "cats" for precise results.
