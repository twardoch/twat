
## Objective

Our goal is to clean up 

- ./plugins/repos/twat_audio/
- ./plugins/repos/twat_image/
- ./plugins/repos/twat_genai/
- ./plugins/repos/twat_llm/
- ./plugins/repos/twat_speech/
- ./plugins/repos/twat_text/
- ./plugins/repos/twat_video/ 

with help of the code in 

- ./reference/ 
- ./reference/bin-img-vid/

I want the code to work so that we have two packages for the "outreach" to AI APIs & models:

- ./plugins/repos/twat_llm/ provides an interface reaching out to text-heavy large language model APIs & models and some LLM-powered text operations
- ./plugins/repos/twat_genai/ provides an interface reaching out to generative AI APIs & models that deal with speech, audio, image and video (so scope beyong the twat_llm scope)

And then I want these packages to serve as user-facing APIs that in the back utilize twat_llm and twat_genai but also various algorithmic solutions. 

- ./plugins/repos/twat_speech/ for speech-related operations (text to speech, speech to text, speech to speech etc.)
- ./plugins/repos/twat_audio/ for audio-related operations beyond speech (audio-to-audio, text-to-audio- audio-to-text etc.)
- ./plugins/repos/twat_video/ for video-related operations (which may include text to video, audio to video, image to video, video to audio etc.)
- ./plugins/repos/twat_image/ for image-related operations (which may include stills from videos, and including text-to-image, image-to-image, image-to-text etc.)
- ./plugins/repos/twat_text/ for text-related operations involving LLMs and algorithimc solutions 

Importantly, we have LOTS of interesting code in ./reference/bin-img-vid/ for image and video processing. And we have stuff like reference/chutes_image and reference/bin-img-vid/imgnanobanatrans.py reference/bin-img-vid/imgquotio.py and others that would need to be split between twat_genai and twat_image — I’m very interested in all those. And I’m very interested in a wide range of backends to be implemented in twat_genai 

One of the goals should be that ALL or NEARLY ALL tools that we have in reference/bin-img-vid which looks like something that might be useful for several users, these tools should be rewritten so that they utilize our twat code. Only clear one-offs inside reference/bin-img-vid should be left as is.
